# Three.js Forest Prototype

Небольшой учебный прототип кинематографичного 3D-сайдскроллера на Three.js. Персонаж движется вдоль заданной пространственной траектории, поэтому камера раскрывает глубину леса без свободного ухода игрока с маршрута. Первая секция проверяет бег по наклонным поверхностям и прыжок через лесной ручей.

## Запуск

```bash
npm install
npm run dev
```

## Управление

- `A` / `D` или стрелки — движение;
- `Space`, `W` или стрелка вверх — прыжок;
- `R` — возврат к последней контрольной точке;
- на телефоне — экранные кнопки движения и прыжка.

## Что уже реализовано

- полностью трёхмерная лесная сцена с перспективной камерой;
- Catmull-Rom-траектория, одновременно задающая путь, поверхность и направление персонажа;
- фиксированный шаг симуляции `1/120 с`;
- буфер прыжка и короткое «прощение» после схода с края;
- контрольная точка перед разрывом;
- одновременное сенсорное движение и прыжок через Pointer Events;
- сброс ввода при потере фокуса;
- плавная кинематографичная камера и ограничение плотности пикселей;
- ручей с направленным течением, рябью, бликами и пеной у берегов;
- процедурный лес, дождь и туман;
- расширенные боковые участки леса: дальние деревья, подлесок, пни, дополнительные валуны и дымка над водой;
- промышленная деревянная лестница, восстановленная по четырём ракурсам: 15 ступеней, две дорожки, закрытые дощатые боковины и три линии перил;
- более светлая экспозиция с отдельным заполняющим освещением;
- первый объект из конвейера `img2threejs`: поваленный ствол с корнями, ветвями, сокетами, коллайдером и группами разрушения.

## Структура

- `app/GameScene.tsx` — сцена, уровень, управление и симуляция;
- `app/game/level.ts` — единая 3D-траектория, разрыв и геометрия земли;
- `app/models/createFallenTreeModel.ts` — процедурная фабрика первого лесного объекта;
- `app/models/createIndustrialStaircaseModel.ts` — процедурная фабрика лестницы с узлами, точками крепления и коллайдером;
- `artifacts/img2threejs/fallen-tree` — референс, анализ, оценка и спецификация объекта;
- `artifacts/img2threejs/industrial-staircase` — четыре референса, анализ, инвентаризация деталей и спецификация лестницы;
- `app/globals.css` — полноэкранная оболочка и сенсорный интерфейс;
- `app/page.tsx` — точка входа.

`guideCurve` является единым источником формы уровня для визуальной геометрии, направления движения и расчёта контакта со склонами. Физический движок стоит подключить, когда появятся движимые ящики, рычаги и более сложные головоломки.

Для коры сохранены извлечённые из референса карты albedo, roughness, height, normal и AO. Оценка уверенности конвейера — `0.86`; визуальная проверка модели по нескольким ракурсам остаётся следующим этапом.

## Экспорт лестницы

Команда `python3 scripts/export-industrial-staircase.py` создаёт локальный архив `exports/IndustrialStaircase_OBJ_Textures.zip`: основную модель OBJ/MTL с четырьмя именованными группами, отдельный OBJ с коллайдерами `UCX_`, пять наборов PBR-текстур и инструкции импорта в Blender и Unreal Engine. Сам архив не хранится в Git, чтобы не дублировать опубликованные в `docs/models/` модель и текстуры.

Крупные боковые формы используют физическую фаску из двух сегментов: 12 мм на вертикальных досках, 18 мм на диагональных профилях и 15 мм на нижних балках. OBJ сохраняет сшитые позиции и пользовательские нормали, поэтому большие плоскости остаются ровными, а переходы и торцы получают читаемый блик.

При каждой сборке экспортёр создаёт четыре контрольных ракурса, лист `Audit/ComparisonSheet.png` и пять диагностических проходов с попиксельным Z-буфером. Правила независимой проверки хранятся в `Audit/audit-contract.json`: агент оценивает силуэт и пропорции, конструкцию, ритм ступеней и перил, материалы и согласованность всех четырёх видов, затем записывает оставшиеся расхождения и одно решение для следующего прохода. Финальный архив также содержит агентский отчёт `Audit/AUDIT_REPORT_RU.md`.

## Model QA Lab

Отдельный статический просмотрщик находится в `model-viewer/` и собирается в каталог `docs/` командой:

```bash
npm run build:model-viewer
```

Он загружает OBJ/MTL из реестра или по публичной ссылке GitHub, показывает материалы, глиняный шейдинг, нормали, глубину, ориентацию граней и каркас. Встроенный аудит проверяет индексы, открытые и неманифолдные рёбра, вырожденные и повторяющиеся грани, UV, пользовательские нормали и согласованность порядка вершин с нормалями; отчёт можно скачать в JSON.

Workflow `.github/workflows/pages.yml` собирает и публикует этот каталог на GitHub Pages при каждом обновлении ветки `main`. Чтобы добавить следующую модель, поместите её пакет в `exports/`, добавьте запись в `model-viewer/public/models/registry.json` и при необходимости расширьте копирование в `scripts/build-model-viewer.mjs`.
